## 📌 Objetivo do Sistema
Este é um script desenvolvido para uma campanha de conscientização ambiental de uma companhia de saneamento. O programa classifica o perfil de consumo de água dos imóveis com base no tipo (comercial, casa ou apartamento) e na quantidade de metros cúbicos ($m^3$) gastos mensalmente, emitindo alertas educativos para os moradores.

## ⚙️ Funcionalidades
- Leitura do tipo de imóvel e consumo mensal.
- Classificação automatizada em:
  - Tarifa Comercial.
  - Consumo Econômico.
  - Consumo Moderado.
  - Consumo Excessivo.
